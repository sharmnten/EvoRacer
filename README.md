# EvoRacer
EvoRacer is a top-down racing game where you can race against AI drivers. 
[Play EvoRacer in your browser](https://sharmnten.github.io/EvoRacer/)

## About the Training Loop
The training loop follows principles of genetic evolution, where the top five individuals of each generation become the parents for the next. The next generation consistents of mutated versions of the parents. Training can take a while, so if you are in a hurry, I recommend you play against my trained version, as it was trained for about an hour to be as fast as possible around the track.
